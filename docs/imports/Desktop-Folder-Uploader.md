# PhotoView.io Desktop Folder Uploader

The desktop folder uploader lets any photo application publish to PhotoView.io if it can export images into a folder.

This is useful for:

- Topaz Photo and Topaz Gigapixel
- Capture One
- Photoshop
- Photo Mechanic
- DxO PhotoLab / PureRAW
- ON1 Photo RAW
- Luminar
- Affinity Photo
- Pixelmator Pro
- RawTherapee
- darktable, until the native Lua exporter is built

## How It Works

1. Open `Settings > Imports > Smart Folders` in PhotoView.io.
2. Create one or more named routes. Each route connects one local folder to one PhotoView portfolio.
3. In Topaz or another photo app, export JPEG, PNG, WebP, HEIC, HEIF, or TIFF files into the matching folder.
4. Copy and start the PhotoView.io watcher command.
5. New files are uploaded to the matching portfolio and marked as uploaded in `.photoviewpro-uploaded.json`.

One watcher command can manage up to 12 folder-to-portfolio routes. The older single-folder command remains supported.

## Run The Watcher

```bash
npm run photoviewpro:watch -- \
  --folder "$HOME/Pictures/PhotoView-Exports" \
  --api-url https://photoview.io \
  --api-key YOUR_IMPORT_KEY \
  --gallery "Travel Portfolio"
```

## One-Time Scan

```bash
npm run photoviewpro:watch -- \
  --folder "$HOME/Pictures/PhotoView-Exports" \
  --api-url https://photoview.io \
  --api-key YOUR_IMPORT_KEY \
  --gallery "Travel Portfolio" \
  --once
```

The command copied from the Smart Folders page uses `--routes` with an encoded configuration so one process can watch every saved route. Do not edit the encoded value manually; update the routes in PhotoView.io and copy a fresh command.

## Options

- `--folder`: folder to watch.
- `--api-url`: PhotoView.io base URL.
- `--api-key`: the private 90-day import key generated in PhotoView.io under `Settings > Imports`.
- `--gallery`: gallery or portfolio name.
- `--client`: optional client/project name.
- `--public`: mark imported gallery intent as public.
- `--recursive`: include nested folders.
- `--once`: scan once and exit.
- `--interval`: watch interval in seconds. Default is `5`.
- `--routes`: encoded multi-folder configuration generated by PhotoView.io.

## Supported Files

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`
- `.heic`
- `.heif`
- `.tif`
- `.tiff`

## Environment Variables

Instead of command-line flags, you can use:

```bash
PHOTOVIEWPRO_WATCH_FOLDER="$HOME/Pictures/PhotoView-Exports"
PHOTOVIEWPRO_API_URL="https://photoview.io"
PHOTOVIEWPRO_IMPORT_API_KEY="YOUR_90_DAY_SUBSCRIBER_IMPORT_KEY"
PHOTOVIEWPRO_GALLERY_NAME="Travel Portfolio"
PHOTOVIEWPRO_CLIENT_NAME="Optional Client"
PHOTOVIEWPRO_MAKE_PUBLIC="false"
```

## Photo App Setup Notes

- Topaz Photo / Topaz Gigapixel: choose a saved Smart Folder as the export destination for finished images.
- Capture One: create a process recipe that exports to the watch folder.
- Photoshop: export final files to the watch folder, or use an action/batch process.
- Photo Mechanic: save selected photos or processed copies to the watch folder.
- DxO / ON1 / Luminar / Affinity / Pixelmator: export finished display images to the watch folder.
- RawTherapee / darktable: export queue output to the watch folder.

## Current Behavior

- Uploaded files are stored in the configured PhotoView.io photo storage provider. Production should use Cloudflare R2; the legacy Vercel Blob provider is only used when explicitly selected.
- Imports are attached to the subscriber workspace and named portfolio.
- Portfolio-count, subscription-write, and storage capacity are enforced.
- Import keys are subscriber-specific and expire after 90 days.

## Use Multiple Folders With Multiple Website Embeds

Each Smart Folder route should use a different local folder and a different destination portfolio. For example:

- `~/Pictures/PhotoView-Wildlife` uploads to the `Wildlife` portfolio.
- `~/Pictures/PhotoView-Portraits` uploads to the `Portraits` portfolio.
- `~/Pictures/PhotoView-Architecture` uploads to the `Architecture` portfolio.

Set each destination portfolio to Public and allow it in embeds. Then open `Settings > Sharing`, create a saved embed profile for each outside website or page, choose the matching portfolio, and copy that profile's iframe code to the external site.

The iframe remains hosted by PhotoView.io. New visible photographs delivered through the Smart Folder appear in the corresponding embed without replacing its code. Hidden photographs are excluded. Private link, Password, and client-portal portfolios cannot be embedded.
